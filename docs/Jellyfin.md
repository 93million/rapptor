# Jellyfin

Jellyfix in an opensource platform for playing and sharing videos, music and photos

## Installation

Jellyfin can be installed from the Rapptor App Store. When you open the Jellyfin app for the first time on Rapptor, you will be saked to create a username and password. Make a note of this

## Playing Jellyfin content on TVs

Jellyfin clients exist for many platforms. If you are installing it on a TV check the app store that comes with the TV. A list of clients can be found at [jellyfin.org/downloads](https://jellyfin.org/downloads/)

### Configuring Jellyfin client

When connecting to Jellyfin server, enter the address as follows: `https://<rapptordomain>:8920`. For example if your Rapptor domain is jonny.rapptor.wtf then enter `https://jonny.rapptor.wtf:8920`

Enter the username and password you created when you first launched Jellyfin

## Resetting the username and password

If you have forgotten your username and password you can reset Jellyfin by uninstalling and reinstalling it. This will not delete any media you have but your accounts and settings we be removed and you will be asked again to create a new account when you open Jellyfin for the first time.
